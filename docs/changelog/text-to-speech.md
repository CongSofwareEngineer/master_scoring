# Changelog: Chuyển văn bản thành giọng nói (TTS tiếng Việt)

> Hiện trạng logic: [../instruction/text-to-speech.md](../instruction/text-to-speech.md)

- 2026-11-07 | Thêm mới | Chuyển văn bản thành giọng nói: trang TTS tiếng Việt chạy offline bằng `onnxruntime-node` + model VITS ONNX (facebook/mms-tts-vie qua Xenova/mms-tts-vie; vits-vietnamese-v2 và pyl5/vits-vietnamese sửa được repo), giọng Nam / Nữ / Trẻ em bằng đổi cao độ (YIN + WSOLA + resample), đọc số / ngày / % thành chữ, tải model có tạm dừng + SHA-256, lưu .wav — yêu cầu thêm tab chuyển text thành giọng nói; 2 model kia không có repo ONNX công khai nên cho nhập repo
- 2026-11-07 | Sửa | Model TTS & tải model: bỏ 2 model không tải được (`vits-vietnamese-v2` không có repo công khai; `pyl5/vits-vietnamese` trả HTTP 401 = không tồn tại; các repo VITS tiếng Việt khác chỉ có .safetensors/.pth), thay bằng Piper vi_VN vais1000 (rhasspy/piper-voices) và Piper 5 giọng (CakeByVPBank); nguồn nhận thêm đường dẫn file .onnx / URL, tự nhận định dạng VITS / Piper, liệt kê theo thư mục + theo trang, báo lỗi rõ repo chỉ có bản PyTorch — người dùng báo 2 model kia tải không được
- 2026-11-07 | Thêm mới | Đọc bằng model Piper: phiên âm tiếng Việt bằng bảng âm tiết `vi-ipa.json` sinh sẵn từ espeak-ng (script `scripts/gen-vi-ipa.mjs`, app không kèm espeak GPL-3 18 MB), chạy Piper với `sid` + tốc độ qua `length_scale`, chọn người đọc (tự theo Nam / Nữ hoặc chọn tay), giữ nguyên cao độ khi người đọc đúng giới tính — có giọng nam / nữ thật, tự nhiên hơn đổi cao độ
- 2026-11-09 | Sửa | Nạp onnxruntime-node: nạp bằng `createRequire` từ `app.getAppPath()` (CJS, hỗ trợ asar) rồi mới thử `import()`; thông báo lỗi kèm hướng xử lý (bộ cài thiếu gói / không có binary cho nền tảng / Windows thiếu VC++ Redistributable) — máy người dùng Windows báo `Cannot find package 'onnxruntime-node' imported from …app.asar…` do bộ cài build từ node_modules thiếu gói
- 2026-11-09 | Thêm mới | TTS từ file (mỗi dòng 1 file): chế độ "Từ file" — mở file văn bản (txt, md, html/xml, srt/vtt, csv/tsv, json, Word, Excel, PowerPoint, OpenDocument, EPUB; tự nhận bảng mã), tách mỗi dòng có chữ thành 1 file, màn xem trước (số file voice<N>, sửa chữ, bỏ chọn, hiện dòng bị bỏ + lý do, cảnh báo dòng quá dài / từ Piper không đọc được, nghe thử), chọn thư mục 1 lần rồi xuất lần lượt voice1.wav, voice2.wav… (ghi đè, dừng được, dòng lỗi bỏ qua, nghe lại, mở thư mục) — người dùng cần đọc cả file nhiều đoạn thành nhiều file âm thanh theo thứ tự, và muốn kiểm tra cách tách dòng trước khi xuất
