# Changelog: Trợ lý dữ liệu (Kế toán AI)

> Hiện trạng logic: [../instruction/data-chat.md](../instruction/data-chat.md)

- 2026-10-16 | Thêm mới | Trợ lý dữ liệu: mở nhiều file Excel / CSV (.xlsx .xls .csv .tsv), nhận diện tiêu đề / kiểu cột / số kiểu VN / dòng Tổng cộng, nạp vào SQLite trong RAM; chat với AI kế toán (Local / Cloud) trả lời bằng SQL chỉ-đọc, kèm truy vấn đã chạy — admin cần tổng hợp số liệu từ file bằng câu hỏi tự nhiên, số phải chính xác và kiểm tra lại được
- 2026-10-16 | Thêm mới | Tìm kiếm trong bảng dữ liệu: ô tìm (Ctrl/Cmd+F) + chọn cột, lọc ở main trên toàn bộ bảng không phân biệt hoa thường / có dấu (hàm SQL `unaccent`), nhận số kiểu VN / US, tô sáng chỗ khớp, cột # giữ số dòng gốc — admin cần dò tới đúng dòng dữ liệu để kiểm tra số liệu / câu trả lời của AI đúng hay sai
- 2026-10-16 | Thêm mới | Biểu đồ / bảng trong câu trả lời: AI trả `charts` (cột đứng, thanh ngang, đường, tròn, bảng) kèm SQL, app chạy SQL lấy số liệu và vẽ SVG (tooltip, chuyển Biểu đồ / Bảng, phóng to, màu đã kiểm tra mù màu) — admin muốn xem số liệu trực quan, số trên biểu đồ phải lấy từ dữ liệu thật chứ không do AI tự ghi
- 2026-10-16 | Sửa | Biểu đồ toàn số 0: tự sửa tên cột viết trong nháy đơn (`AVG('eth')` → `AVG("eth")`) trước khi chạy SQL, xoay kết quả 1 dòng nhiều cột thành nhiều nhóm, biểu đồ toàn 0 thì bắt AI kiểm tra lại, prompt cấm nháy đơn cho tên cột + hướng dẫn UNION ALL cho dữ liệu dạng cột — biểu đồ "trung bình từng token" ra 0 vì SQLite coi 'eth' là chuỗi chữ
- 2026-10-16 | Thêm mới | Đổi kích thước khung chat: kéo mép trái để rộng / hẹp (nhấp đúp về mặc định), nút Phóng to khung chat và Thu gọn thành dải bên phải, nhớ độ rộng theo máy — khung chat cố định bất tiện, admin muốn lúc tập trung xem dữ liệu, lúc tập trung chat
- 2026-10-16 | Sửa | Câu trả lời của AI kế toán: prompt yêu cầu trả lời dạng báo cáo đầy đủ (kết luận, chi tiết số liệu, phân tích / nhận xét, cách tính, cảnh báo, gợi ý), khuyến khích truy vấn phụ, `maxTokens` 1800 → 4096, lịch sử mỗi lượt 1.500 → 2.500 ký tự — admin thấy câu trả lời quá ngắn gọn, muốn phân tích dài và chi tiết hơn
- 2026-10-16 | Thêm mới | Thêm loại biểu đồ: cột chồng, thanh ngang chồng, vùng (gradient), đường 2 trục, kết hợp cột + đường, tròn đặc (tách khỏi tròn rỗng), vùng cực, radar, phân tán, bong bóng (chuỗi tối đa 4 → 6, nhận tên loại khác của model, tự hạ loại khi thiếu dữ liệu) — admin cần nhiều loại biểu đồ như danh sách ví dụ của Chart.js
- 2026-10-16 | Sửa | Hỏi đáp của AI kế toán: chuyển từ "AI trả JSON {action:sql|answer} trong nội dung" sang tool calling chuẩn OpenAI theo khung agent `src/main/agents/` (công cụ `run_sql`, `draw_chart`; câu trả lời cuối là Markdown); lỗi SQL / biểu đồ toàn 0 trả về qua lượt `tool`; 6 vòng công cụ thay 4 truy vấn; `datachat/agent.ts` → `datachat/ask.ts` — làm lại kiến trúc agent cho đúng chuẩn (theo mẫu folder `agents` của giat-say-sieu-sach-client), body gửi Local / Cloud đúng định dạng tools / tool_calls
- 2026-10-16 | Sửa | Prompt hệ thống AI kế toán: viết gọn lại (~6.000 → ~2.200 ký tự phần cố định), mô tả cột dạng `đầy= / khác=` có chú giải một lần, chuyển hướng dẫn chọn loại biểu đồ + mẹo so sánh giữa các cột sang mô tả công cụ `draw_chart` (thay gợi ý `UNION ALL` bằng cách 1 dòng nhiều cột mà app đã tự xoay) — prompt quá dài, tốn token mỗi vòng gọi AI
- 2026-10-16 | Sửa | Truy vấn SQL / biểu đồ: tên trong nháy kép không khớp cột (`AVG("ETH")` khi cột là `gia_eth`) không còn ra 0 — chạy bản `"…"` → `[…]` để SQLite báo lỗi, tự đổi theo tiêu đề gốc nếu trùng, không thì trả lỗi kèm danh sách cột cho AI sửa — biểu đồ cột đứng "Giá trị trung bình của các token" vẽ toàn 0 do SQLite coi tên cột sai là chuỗi chữ
